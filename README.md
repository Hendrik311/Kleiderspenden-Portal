# Kleiderspenden-Portal

Prototyp eines Registrierungsportals für Kleiderspenden (Fallstudie IPWA01-01, IU Internationale Hochschule).

## Funktionen
- Registrierung einer Kleiderspende mit Eingabeprüfung
- Wahl der Übergabeart (Abholung oder Abgabe) mit angepasstem Formular
- Bestätigungsseite mit Registrierungsnummer

## Technologien
HTML, CSS, JavaScript, Vue 3 und Bootstrap 5.3.3 (jeweils über CDN)

## Start
Die Datei index.html im Browser öffnen. Eine Installation ist nicht erforderlich.

## Hinweis
Der Prototyp besitzt kein Backend, es werden keine Daten gespeichert.
